Read-only refresh into a **new** folder (choose a fresh timestamp each time):

```bash
rtk proxy asc --profile minimo --read-only apps list --bundle-id com.khlebobul.boardBuddy --output table
rtk proxy asc --profile minimo --read-only versions list --app 6743980638 --output table
rtk proxy asc --profile minimo --read-only metadata pull --app 6743980638 --app-info 86b69016-abd6-4a29-98d9-858f4f7cd599 --version 1.3.10 --platform IOS --dir .asc/snapshots/NEW-TIMESTAMP
```

Validation only; no upload:

```bash
rtk proxy python3 store_screenshots/scripts/validate_metadata.py
rtk proxy asc --profile minimo metadata validate --dir metadata --output table
```

The validator checks name/subtitle ≤30 characters, keywords ≤100, promotional text ≤170, description/What's New ≤4000 and preservation of existing URLs/release notes. On a fresh clone, pull into a snapshot, copy to `metadata/` only if it does not exist, then restore supplied copy from your private backup. Store text intentionally does not live in Git; there is no destructive auto-sync or auto-push.
